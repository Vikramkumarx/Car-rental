# 🚗 CarRentIndia - Premium Car Rental Web App

A modern, responsive car rental booking platform built with **Next.js 16**, designed specifically for the Indian context.

![Project Preview](public/bmw_car_img.png) 
*(Note: Screenshots are placeholders)*

## ✨ Features

- **🇮🇳 Indian Context**: Rent popular Indian vehicles like **Toyota Fortuner**, **Mahindra Scorpio N**, **Royal Enfield**, and more.
- **📱 Fully Responsive**: Works perfectly on both Desktop and Mobile devices.
- **🔍 Smart Search & Filters**: Filter by category (Gadiya, Bikes, Trucks) or search by name.
- **❤️ Favorites System**: Save your dream rides to your favorites list.
- **📅 Booking System**: Interactive booking modal with date validation and cost calculation.
- **👤 User Dashboard**: View your booking history in the "My Bookings" section.
- **🎨 Premium UI**: Glassmorphism effects, smooth animations, and a polished design using standard CSS.

## 🛠️ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: CSS Modules (Custom Premium Styles)
- **Icons**: [React Icons](https://react-icons.github.io/react-icons/)

## 🚀 Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 📂 Project Structure

- `src/app/page.tsx`: Main application logic (Home, Search, Booking).
- `src/app/page.module.css`: Custom styling for the application.
- `public/`: Assets and images.
